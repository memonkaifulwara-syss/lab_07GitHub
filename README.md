

\# Storage Estimator



\## Purpose

This program estimates the storage needed for photos and videos.



\## How to Run

Run the file using Python:

python storage\_estimator.py



\## Example Input

Number of photos: 10

Number of videos: 2



\## Example Output

Photo storage: 30 MB

Video storage: 200 MB

Total storage: 230 MB
